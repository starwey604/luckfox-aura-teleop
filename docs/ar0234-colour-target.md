# AR0234 浏览器色彩靶

本机原生 Python 标准库即可运行，不需要安装依赖，不使用 Distrobox，不启流摄像头。
用于核对实际 Bayer 排列及观察偏色，不是屏幕到屏幕延迟计时器，也不是标定过的光源。

```sh
cd /home/ww/codings/luckfox-aura-teleop
./tools/calibration-screen
```

2026-10-16 本机 Wi-Fi IP 是 `192.168.8.5`。平板连接同一局域网后访问
`http://192.168.8.5:8765/`；如果 DHCP 地址改变，以 `ip -br -4 addr show wlan0` 为准。
若连接不上，检查两端网络、AP 客户端隔离及本机防火墙；程序不自动修改网络或防火墙。
默认监听所有接口；用 `--bind <本机地址>` 可以限制监听地址。
这是无密码的局域网测试服务，不要转发到公网；Ctrl+C 停止。

页面支持全屏、隐藏控制面板、纯色、九宫格色块、八级灰阶和自定义 `#RRGGBB`。
所有打开的浏览器从服务器同步当前目标，本机可以在不碰平板的情况下切换：

```sh
./tools/calibration-screen --set chart
./tools/calibration-screen --set red
./tools/calibration-screen --set green
./tools/calibration-screen --set blue
./tools/calibration-screen --set white
./tools/calibration-screen --set '#606060'
```

若服务仅绑定某个网卡地址，控制命令也要使用 `--url http://<该地址>:8765`。
`--port` 默认8765，`--initial` 默认gray；切换后至少等待2秒再采样，
轮询同步不保证精确呈现时间，不能拿来测毫秒延迟。

## 布置与结果边界

- 关闭护眼、夜间模式、自动亮度、自适应色温，使用固定亮度/显示模式。
- 让两颗相机都看到屏幕；尽量正对，屏幕占画面中部较大区域，避免反光。
- 拍色块时可轻微离焦，使屏幕RGB子像素充分混合，避免像素栅格造成摩尔纹。
  这只用于色彩诊断；不要据此改变最终对焦。
- 默认原色和“白”使用192/255，降低过曝风险，但仍需检查RAW是否饱和。
  75%指RGB码值，不是物理亮度75%。
- 九宫格从左到右、从上到下：红绿蓝 / 青品红黄 / 黑灰白。
- 曝光约5ms时屏幕PWM、刷新与相机可能产生条纹；出现条纹时先判断光源影响。
- 红/蓝参考能帮助判别Bayer相位，白屏本身不能区分所有排列。
- 屏幕光谱和色彩管理影响结果，在这个屏幕上得到的通道增益不能直接当成室内照明的最终白平衡。
  最终白平衡仍建议用实际使用灯光下的哑光白纸/灰卡。
- **屏幕显示黑色不能测传感器黑电平**：必须用不透光的镜头盖或遮挡物完全遮光，
  并在相同曝光/增益下采集RAW；压缩视频/YUV的黑色值不能替代RAW黑电平。

原始图像、日志和统计中间文件应放在忽略目录 `captures/`、`artifacts/` 或 `logs/`，
不提交到Git。服务只提供固定页面和状态API，不提供工作区文件下载。
