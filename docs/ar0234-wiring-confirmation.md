## 已从现有资料确认（2026-10-12）

以 [Luckfox 官方 Aura 原理图](https://github.com/LuckfoxTECH/luckfox-aura-docs/blob/main/Hardware/Schematic/Luckfox-Aura.pdf)
的 MIPI CSI 区域为准，H3/CSI0、H4/CSI1 的引脚编号与商家模组图纸一致。
之前用树莓派通用编号比较得到的“供电脚编号相反”不能直接套用到 Aura。
该版本 Aura 原理图 SHA256：
`036cb8f0ba9f4e5dcf82d46a8e75c51fd7e41310c12ba9cfb8680cd0b33c5b5b`。
应核对实物板的修订与接口丝印，不将原理图编号当作插座照片的左右位置。

| Pin | Aura CSI0 / CSI1 | DECXIN 模组 |
|---|---|---|
| 1 | 3.3V | 3.3V |
| 2 / 3 | SDA / SCL | SDA / SCL |
| 4、7、10、13、16、19、22 | GND | GND |
| 5 / 6 | CSI IO0 / IO1 | NC / NC |
| 8 / 9 | D3 P / N | MDP3 / MDN3 |
| 11 / 12 | D2 P / N | MDP2 / MDN2 |
| 14 / 15 | CLK P / N | MCP / MCN |
| 17 / 18 | D1 P / N | MDP1 / MDN1 |
| 20 / 21 | D0 P / N | MDP0 / MDN0 |

CSI0 接 I²C4，CSI1 接 I²C3；CSI0 的 SDA/SCL 在主板上通过 4.7k 上拉到 3.3V。
芯片 DOVDD=1.8V 与模组外部 I²C 电平不是一回事。模组是否有电平转换或
可接受外部 3.3V，要由实物电路/电压测量确认；现有图纸没有给出该电路。
模组 5/6 为 NC，不能给它套用旧 MIA1321 外部 reset GPIO。

## 同向/反向排线

同向与反向通常描述排线两端裸露触点位于相同面还是相反面，不能直接当成
“引脚同序/反序”。正确排线取决于两端插座实际触点位置、pin 1 位置和安装姿态。
商家图纸标明模组为下接触；Aura 原理图的电气符号不说明完整机械触点结构。
[Aura 官方 CSI 安装说明](https://wiki.luckfox.com/Luckfox-Aura/Debian13/CSI/)
要求主板端排线金属触点朝以太网接口，但其中摄像头端说明针对官方 IMX415，
不能自动套用给 DECXIN。

本项目要求实际连线保持同号：1→1、2→2、3→3、14→14、15→15、
17→17、18→18、20→20、21→21；其余同理。
若接成 1→22，3.3V 可能接入模组地；其它错误映射也可能让电压进入信号脚。
可能发生电源短路或器件损坏，不能靠“上电不出图就换另一根”确认排线。
有保护电路也不代表一定能避免损坏。

确认顺序：

1. 两端都断电，移除 USB、PoE 等供电来源；插拔排线保持断电。
2. 按模组底视图与主板丝印/实物针脚确定两个 pin 1，确认金属触点贴合
   插座的实际弹片面，不按蓝色加强片猜测。
3. 用万用表导通/电阻档，优先在排线独立、两端针序已标记时核对导线。
   装入插座后可从可访问的焊盘/测试点核对 3.3V→3.3V、SDA→SDA、SCL→SCL、
   GND→GND；不要用粗探针跨接 0.5mm 相邻触点。
4. 上电前检查供电与地没有稳定的近零欧短路。电容可能引起短暂读数变化，
   不把一声蜂鸣当作完整判断。
5. 只有触点和映射确认后，才上电进行软件识别。

没有方便测量的引出点时，需要实物接口近照或 FPC 转接板来确认，不能从目前
的电气表可靠指定同向或反向。两种排线都有并不构成可以轮流上电试接的依据。

## 不等待额外资料的软件验证

可先把“模组自带 24MHz 晶振、内部稳压及上电复位”作为明确的实验假设；
由 NC 引脚和 XMCLK 设置支持这一方向，但不能据此宣称内部电路已确认。
不要接主板 MCLK/reset 到 NC；24MHz fixed-clock 节点只描述时钟，并不会输出物理时钟。

确认电气连接后，先在相应 camera I²C 总线上读取候选地址的芯片 ID。
参考模组常用 7-bit 地址 0x10，DECXIN 地址未给出，不能写死当作已确认。
优先做已知 chip-ID 寄存器读取，而不是写初始化表去试地址。
驱动预期 `0x3000` 返回 `0x0a56` 或 `0x1a56`。
芯片 ID 成功只验证识别；之后还要以实际 RAW 帧率、尺寸和 CSI 错误验证
24MHz/720p 时序模型。失败时区分供电、触点、地址和时钟，不直接调 PLL。
