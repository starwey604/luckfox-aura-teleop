# AR0234 手动 ISP 白平衡与黑电平

2026-10-16，沿用 #19 内核完成用户白纸场景的实机调校。
**无需刷写镜像；正常 `/userdata/teleop-sender` 与 launcher 已更新。**
当前候选能明显消除白纸偏绿，参数保持显式启用，不自动改变所有环境的默认色彩。

## 使用

板端双路：

```sh
ISP_WB=1.4375,1,1,1.5625 \
ISP_BLACK_LEVEL=171,167,167,170 \
/userdata/run-ar0234-stereo
```

两个四元组的顺序均为 **R、Gr、Gb、B**。
曝光仍为735行（约4.998ms）、模拟增益48、数字增益512、VBLANK506，约119.95fps；
GOP15/CAVLC/4×4/不拆slice/30Mbps每路及wrap0保持不变。

如果需要约4ms曝光，可在上面的命令中加 `EXPOSURE=588`；已做120帧单路验证，
但没有把它作为新默认。调低曝光会减少进光量，不能仅凭一张白纸图判断室内实际场景画质。

单路 camera1 直接调用：

```sh
/userdata/teleop-sender --camera 1 \
  --width 1280 --height 720 --fps 120 \
  --wrap-lines 0 --slice-ctus 0 --entropy cavlc --transform 4x4 \
  --isp-wb 1.4375,1,1,1.5625 \
  --isp-black-level 171,167,167,170
```

直接sender不会自动设置sensor的曝光/增益/VBLANK；这些仍由launcher或V4L2控件配置。
程序持续运行需要用户自行启动；本轮自动测试均已停止，没有留下长期采集任务。
恢复原ISP状态：停止sender，去掉这两个环境变量/命令行参数再启动。
已经验证参数退出后再启动不带ISP参数的sender，AWBGAIN和BLS均恢复OFF。

## 实现方式

- 新增 `src/aura-sender/src/manual_isp.hpp`，通过MEDIA controller找到对应
  `rkisp0/1` 的 `rkisp-input-params`，不把video30/video38写死。
- 核验当前ISP35 metadata ABI，申请两个小型参数buffer，将手动配置作为首帧参数提交。
  使用的是参数队列，不是新增视频帧缓存；没有启动RKAIQ/自动曝光线程。
- 只更新AWB_GAIN/BLS的配置与使能mask，不碰CCM、gamma、降噪、sensor时序等模块。
- 白平衡按Q8量化，这组值实际为 `[368,256,256,400]`。
  主gain0/1/2使用对应值，第二级awb1保持256，避免重复应用增益。
- `--isp-black-level` 是**ISP BLS寄存器单位**，范围0..4095，不是RAW10 DN。
- 第一次取到编码帧后，从procfs核验每路AWB使能和R/Gr/Gb/B寄存器值，BLS检查使能；
  不匹配即报错并正常清理。BLS固定值另由这次诊断寄存器快照逐项验证，
  不把“BLS ON”误称为完整固定值回读。
- 参数队列持有到视频采集停止之后，再STREAMOFF和关闭；遵循现有单进程双路MPI清理顺序。
  没有参数时完全不打开ISP metadata队列，保留原行为。
- 增加 `isp.prepared` 初始化故障插桩点；解析错误在SYS_Init之前拒绝。

SDK的 `isp_awbgain_enable()` 关闭分支有可疑的位掩码实现（`val &= CIF_ISP_CTRL_ISP_AWB_ENA`）；
此轮不通过该分支在视频运行中切换OFF。停止VI后释放metadata队列、下次启动恢复默认的路径已验证。
不使用procfs手写ISP寄存器，也未将其他sensor的IQ文件改名套用。

## 白纸结果

用户提供室内灯光下的白纸，camera1采集RAW，避开左下高亮、印章及纸边。
固定RAW ROI `(680,360,100,100)` 无饱和，按此前遮光均值扣除后估计R/B相对G的增益，
选取上述Q8可精确表示的数值。没有按整张图执行gray-world，以免背景影响白纸校准。

下面是各短片第60帧的相同ROI，按FFmpeg默认RGB转换得到的相对颜色对照：

| 设置 | R均值 | G均值 | B均值 |
|---|---:|---:|---:|
| 原配置 | 153.64 | 220.08 | 143.65 |
| 只开白平衡 | 227.49 | 220.75 | 229.52 |
| 白平衡＋BLS | **210.63** | **209.04** | **210.39** |
| 白平衡＋BLS，曝光588行 | 205.84 | 204.46 | 208.94 |

这是短时、依次采样，灯光和纸位置可能变化，不是匹配RAW对的色卡色差评价。
该结果支持当前灯光下中性纸张明显改善，不保证所有物体色彩或其他光源正确。
gamma与CCM仍保持原来的OFF；需要进一步调色时，应另用色卡与受控灰阶。

## BLS尺度实测

用户再次完全遮住camera1，按原曝光/增益分别采集120帧。
解码为NV12保留原始Y码值，跳过10帧后统计110帧，**不使用灰度/RGB转换后的黑值**。
转换到RGB或gray时可能做limited/full-range映射并把小于16的Y裁到0，不能拿来测BLS。

| 设置 | Y均值 | P1 / P50 / P99 | Y为0的比例 |
|---|---:|---|---:|
| 原配置 | 11.058 | 8 / 11 / 14 | 0.00048% |
| BLS四通道都设42 | 8.467 | 6 / 8 / 12 | 0.00291% |
| BLS=171/167/167/170，加WB候选 | 1.706 | 0 / 2 / 4 | 1.416% |

BLS增加42单位，Y降低约2.59，与12bit ISP域到8bit Y的42/16=2.625接近；
结合此前约42DN的RAW10黑场，支持当前模式的**RAW10→ISP BLS约×4**。
最后一行还开启了白平衡且有截零，不能直接拿均值差当严格线性增益测量。
黑场保留少量正值/噪声，未为了追求平均0而继续增加扣除；少量负噪声被裁零是黑电平扣除的预期结果。

实机主BLS寄存器为：A(Gr)=167、B(R)=171、C(B)=170、D(Gb)=167；
CTRL=1，BLS1与OB保持关闭。不同曝光/增益/温度或模组的黑电平应重新核对，
不要把这四个值当成所有模式通用常量。
